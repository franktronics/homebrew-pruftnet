# Pruftnet Homebrew tap

Install Desktop: `brew install --cask franktronics/pruftnet/pruftnet-desktop`

Install Server: `brew install franktronics/pruftnet/pruftnet-server`

Append `-nightly` to a package name for the nightly channel.

See https://github.com/franktronics/pruftnet.app/blob/main/README.md#install for capture permissions and unsigned beta installation.
